Before you install

  • Mac Remapper needs Accessibility access to remap keys system-wide — you'll be prompted to grant it on first launch.
  • The app isn't notarized by Apple yet, so Gatekeeper will warn you the first time you open it (see step 3 below).
  • Your key mappings are stored locally in ~/Library/Application Support/MacRemapper and never leave your Mac.

Installing

  1. Download the .dmg above and open it.
  2. Drag Mac Remapper into your Applications folder.
  3. Since the app isn't notarized yet, right-click (or Control-click) the app and choose “Open”, then confirm in the dialog that appears. You only need to do this once.
  4. Grant Accessibility access when prompted, then start creating profiles from the menu bar icon.
